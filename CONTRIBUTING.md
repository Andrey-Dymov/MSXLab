# Участие в разработке

Опишите проблему или предложение в GitHub Issues. Для изменения кода создайте ветку и pull request с описанием поведения и выполненных проверок.

## Проверки

```sh
npm ci
npm run typecheck
node tests/automation-api.mjs
npm run build
```

Интеграционные тесты требуют подключённых локальных материалов, некоторые запускают Electron и изменяют тестовые проекты. Запускайте их последовательно на копии рабочего окружения. Не используйте несохранённый пользовательский сеанс для тестов.

## Состав репозитория

Не добавляйте ключи, .env, .msxlab-runtime.json, пользовательские диски, состояния эмулятора и локальные настройки. Материалы проектов находятся в отдельном MSXProjects. Не меняйте лицензирование стороннего кода.
