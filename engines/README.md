# Движки

`config.json` задаёт активный движок, путь к поставке и идентификатор адаптера. Проект может закрепить свой engine ID.

WebMSX 6.0.8: https://github.com/ppeccin/WebMSX/releases/tag/v6.0.8

`webmsx-6.0.8/wmsx.js` скопирован из исследовательской песочницы без изменений. SHA-256: `f24443faf9a55a018785eaf2cf291d74e19284e3785b291a2c0ef29af06b07bd`.

Отладочные перехватчики находятся в `public/engine/boot.js` и устанавливаются только во время выполнения. Замена каталога движка не гарантирует совместимость его внутренних функций: версия проверяется до включения отладчика. UI работает через отдельный backend.

Поставка хранится локально и не входит в Git. Лицензия версии 6.0.8 не установлена: см. [проверку](../THIRD_PARTY.md).
