# Проекты COM / MSX-DOS

Создайте проект из `.COM` либо выберите тип **COM · MSX-DOS** в существующем проекте. При смене типа можно выбрать MSX1/MSX2 и добавить сопутствующие файлы с именами DOS 8.3.

Приложение создаёт загрузочный диск с закреплёнными копиями MSXDOS.SYS и COMMAND.COM (MSX-DOS 1), программой APP.COM и AUTOEXEC.BAT. Программа запускается средствами DOS по адресу $0100. Это запуск в настоящем окружении DOS эмулятора, а не подстановка COM в память без загрузки системы.

В Launch setup можно изменить команду `APP`, добавить её аргументы (например `APP INPUT.TXT`), заменить совместимую пару системных файлов и изменить набор файлов диска. MSX-DOS 2/Nextor отдельно не заявлены как поддерживаемое окружение.

Дизассемблер файла COM по умолчанию использует базовый адрес $0100. Для исполняемой программы и точек останова выбирайте CPU или нужный слот RAM. Просмотр файла показывает исходные байты, а не изменённое состояние памяти.

После новой сборки используйте существующее обновление сборки проекта. Настройки окружения и разметка сохраняются; если байты программы изменились, приложение просит проверить соответствие разметки новой сборке. Старые сборки сохраняются. Автоматическая сборка исходников и импорт символов конкретного ассемблера сюда не входят.

## Сборка исходников

В панели **Source Listing** COM-проекта теперь доступен редактор `source/main.asm`, сохранение и кнопка **Скомпилировать и запустить**. Для нового исходника предлагается пример вывода строки через DOS. Настройки компилятора хранятся в `project.json` (`compiler.executable`, `compiler.args`). По умолчанию используется установленный `/opt/homebrew/bin/z80asm` с аргументами `-L -o {output} {source}`.

Аргументы задаются JSON-массивом; `{source}` и `{output}` заменяются абсолютными путями. Запуск без shell, ограничение 60 секунд. Каталог `source` копируется в отдельный временный каталог каждой сборки, поэтому локальные include-файлы можно хранить рядом с главным исходником. Сборка должна создать новый COM именно по `{output}`. Журнал доступен в панели и `research/last-build.log`.

При успехе COM включается в новый загрузочный диск и проект перезапускается. При ошибке исходник и настройки остаются сохранёнными, предыдущий исполняемый файл и текущий эмулятор не заменяются. Настройки окружения DOS сохраняются.

Для z80asm -L импортируются точные адреса именованных меток, определённых в главном исходнике, и комментарии перед/при определении. Это метки адресов, а не автоматически угаданные границы процедур. EQU вне загруженного COM не импортируются. Автоматические метки имеют идентификаторы `compiler:` и заменяются следующей успешной сборкой; ручные сохраняются. При наличии ручной разметки смена сборки требует её проверки. Другие компиляторы можно настроить командой, но их таблицы символов пока требуют отдельного адаптера.
