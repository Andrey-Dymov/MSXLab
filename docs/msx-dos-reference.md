# Справочник MSX-DOS в дизассемблере

Для COM / DOS проектов CALL $0005 отмечается как BDOS. Номер функции передаётся в C. Это соглашение DOS, а не универсальное назначение адреса $0005 в BIOS.

Подсказки работают в CPU и в просмотре RAM-слота. Функция уточняется только по непосредственно предшествующей инструкции LD C,n; это статическая подсказка, не гарантия пути исполнения. Если номер неизвестен, показывается общий вход BDOS.

| C | Имя | Назначение |
|---|---|---|
| 00 | _TERM0 | Завершение программы |
| 01 | _CONIN | Ввод символа с эхом, результат A |
| 02 | _CONOUT | Вывод символа из E |
| 09 | _STROUT | Вывод строки по DE до `$` |
| 0A | _BUFIN | Ввод строки в буфер по DE |
| 0B | _CONST | Проверка готовности ввода |

Полный встроенный перечень содержит 92 функции из спецификации MSX-DOS 2. Названия остальных функций сохранены на языке документа. Поддержка конкретной функции зависит от версии DOS; наличие в справочнике не означает её доступность в DOS 1.

Источники: [Function Specification](https://map.grauw.nl/resources/dos2_functioncalls.php), [Program Interface Specification](https://map.grauw.nl/resources/dos2_environment.php).
