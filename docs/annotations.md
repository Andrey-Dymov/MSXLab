# Единые описания дизассемблера

`resolveAnnotations` возвращает общий список записей: имя, описание, источник, основание и идентификатор. Источники — метки строки проекта, общий справочник BIOS/портов/системных адресов и справочник функций DOS. `StandardReference` выводит этот список в одной колонке во всех трёх просмотрах: CPU, физическая память, файл.

Контекстные правила выбирают запись справочника, но не создают отдельные UI-комментарии. Для DOS правило распознаёт CALL 0005 и непосредственно предшествующую LD C,n. Без достоверно известного номера показывается общий вход BDOS. Для файлов не предполагается текущая карта BIOS. Данные не анализируются как вызовы.

Справочные записи не записываются в проект и не изменяют пользовательские метки. Пользовательское описание и справочная информация могут сосуществовать. Источник и основание отображаются при наведении. Метки строки поступают уже отфильтрованными просмотрщиком по выбранной памяти.

Проверка: `node tests/annotations.mjs`.
