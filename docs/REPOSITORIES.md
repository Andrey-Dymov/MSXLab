# Разделение репозиториев

- MSXLab (публичный): исходники Electron/React, отладчик, тесты лаборатории, документация и инструменты.
- MSXProjects (приватный): отдельные проекты в projects/, включая Calc80 (msxtable), исходники, сборки, диски, исследования и сохранённые сеансы. Также локальные материалы запуска и сторонние справочники.

Рекомендуемая структура:

```text
Development/
  MSXLab/
  MSXProjects/
    projects/
    engines/webmsx-6.0.8/
    resources/environments/msxdos1/
    docs/reference/
    work/
```

После клонирования обоих репозиториев выполнить в MSXLab:

```sh
npm ci
node scripts/link-projects.mjs
npm run build
npm start
```

Можно передать другой путь к приватному репозиторию аргументом скрипта.
Скрипт создаёт относительные ссылки и не заменяет существующие файлы.
Исходники проектов редактируются в MSXProjects/projects; лаборатория видит их через MSXLab/projects.
Публичный репозиторий не включает локальный комплект DOS и движок: одного клонирования MSXLab недостаточно для запуска эмуляции. Доступный пользователю комплект подключается отдельно.

Не коммитить .msxlab-runtime.json: это временный адрес и токен локального API.
Изменения сохраняются двумя независимыми коммитами. Перед коммитом дисков и сеансов желательно завершить запись в приложении. Приватность репозитория не даёт права распространять сторонние материалы.
