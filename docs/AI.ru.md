# Настройка ИИ

[English](AI.md)

ИИ необязателен. В новой установке он выключен; поставщик, модели и ключ не заданы. Аккаунт и ключ автора не входят в поставку.

## Быстрая настройка

1. Получите собственный ключ API и имя доступной модели у поставщика с HTTPS API, совместимым с **Chat Completions**.
2. Откройте **Настройки → ИИ**.
3. Укажите базовый адрес API, например `https://api.example.com/v1`. Окончание `/chat/completions` приложение добавит само.
4. Введите точное имя модели. Резервные модели можно указать ниже, каждую с новой строки.
5. Введите свой ключ в поле пароля, включите ИИ и сохраните настройки.
6. Выделите инструкции в дизассемблере и выберите анализ ИИ. Проверьте предложенное описание перед его сохранением.

Запросы выполняются через **ваш аккаунт поставщика** и могут оплачиваться по его тарифам API. Вход через аккаунт автора и общая подписка не используются. Сохранение настроек не отправляет пробный запрос. Поддерживается совместимый API, а не произвольный сайт с чат-ботом.

## Какие данные отправляются

Выбранные инструкции и относящийся к ним контекст: имена меток, описания и комментарии, адреса, числовые операнды и область памяти. Системная инструкция запрашивает краткое описание на языке интерфейса. Весь проект, ROM и история исполнения автоматически не передаются. Ответ сохраняется в проект только после подтверждения пользователем.

## Хранение ключа

Настройки находятся в `ai.json` в персональном каталоге Electron `userData`, за пределами репозиториев. Обычно это:

- macOS: `~/Library/Application Support/msxlab/`;
- Windows: `%APPDATA%/msxlab/`;
- Linux: `~/.config/msxlab/`.

Переменная `MSXLAB_USER_DATA` может задавать другой каталог.

Новый ключ шифруется через Electron `safeStorage` и привязывается к точному нормализованному адресу API. После смены адреса прежний ключ другому поставщику не отправляется. Пустое поле сохраняет прежний ключ, заполненное — заменяет его. Сохранённый ключ и зашифрованное значение обратно в интерфейс не возвращаются. Не передавайте другим даже зашифрованный файл настроек.

При недоступном системном хранилище секретов сохранение нового ключа запрещено. Незащищённый Linux-режим `basic_text` также не используется. Подробности — в [документации Electron](https://www.electronjs.org/docs/latest/api/safe-storage). После переноса на другой компьютер может понадобиться ввести ключ заново.

## Альтернативная настройка

Можно передать запускаемому процессу `MSXLAB_AI_API_KEY` и `MSXLAB_AI_BASE_URL`. Адрес должен совпадать с настройками. Сохранённый зашифрованный ключ для этого адреса имеет приоритет. Уже запущенное приложение нужно перезапустить, чтобы оно увидело новые переменные окружения. Не записывайте реальные ключи в публикуемые команды, файлы или снимки экрана.

Для прежних установок сохранено чтение `WAVESPEED_API_KEY` и одноимённого поля локального `ai-secrets.json`, но **только для `https://llm.wavespeed.ai/v1`**. Это не начальные настройки новых пользователей. Старый незашифрованный файл автоматически не изменяется и не удаляется. После ввода ключа через настройки зашифрованная версия используется вместо прежней.

## Если не работает

- Ключ отсутствует: укажите собственный ключ для выбранного адреса.
- HTTP 401/403: проверьте ключ и разрешения на модель.
- HTTP 404: проверьте базовый адрес и имя модели.
- HTTP 429: проверьте квоту; при наличии резервных моделей приложение попробует следующую.
- Ключ не расшифровывается: введите его заново на этом компьютере.
- Перенаправления не выполняются: используйте конечный адрес API поставщика.

Ключи, персональные настройки, `.env` и `.msxlab-runtime.json` исключены из Git. Автоматические тесты настроек не обращаются к платным API.
