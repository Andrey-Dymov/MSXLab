# Активность памяти

На цветных полосах карты CPU и VRAM отображаются гистограммы обращений. Кнопка Activity: ON/OFF включает и останавливает сбор с сохранением результата, ↺ очищает накопленную статистику.

- PC — выполненные инструкции, белый слой (CPU).
- R — чтения, голубой слой.
- W — записи, янтарный слой.

По умолчанию выбраны выполнение CPU и записи VRAM. Сбор включён автоматически; при необходимости его можно выключить: точный подсчёт требует дополнительных проверок при выполнении движка и может замедлять игру. Переключатели слоёв управляют только отображением.

Для каждого пикселя вдоль шкалы суммируются обращения адресов соответствующего диапазона. Высота равна log(1 + число обращений) / log(1 + максимум по диапазонам). Каждый слой нормируется независимо, поэтому высоты разных слоёв не показывают их абсолютное соотношение. Подсказка показывает числа. В вертикальной панели амплитуда направлена вправо.

CPU R включает выборку инструкций и операндов. Повторная запись того же значения тоже учитывается. Чтения панелями отладчика исключены. Для VRAM учитываются обращения CPU через порт данных: чтение соответствует возвращённому байту с учётом буфера VDP. Фоновая отрисовка VDP не учитывается.

Статистика накопительная до сброса; восстановление состояния машины её очищает. Адреса CPU логические, без разделения физических банков. Текущая интеграция работает с 16 КБ VRAM MSX1. Исходники WebMSX не изменены.
