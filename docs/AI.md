# Подключение ИИ

В настройках ИИ указываются HTTPS-адрес совместимого Chat Completions API, модели и состояние подключения. Настройки сохраняются локально в ai.json внутри Electron userData. По умолчанию ИИ выключен.

Анализ выделенного ассемблера запускается явной командой пользователя. Основной процесс передаёт выделенный текст настроенному поставщику; для запроса нужны включённая конфигурация и локальный ключ. Ключ читается из WAVESPEED_API_KEY либо ai-secrets.json в Electron userData. Эти файлы и значения не должны попадать в Git.

Клиент поддерживает таймаут и переход к резервной модели при HTTP 429/5xx. Доступность указанных моделей зависит от поставщика. Полное содержимое проектов автоматически не отправляется.
