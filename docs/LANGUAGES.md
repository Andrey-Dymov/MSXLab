# Языковые пакеты

Выбор: **настройки приложения → Язык интерфейса**.

| Код | Язык | Название в меню |
| --- | --- | --- |
| `ru` | Русский | Русский |
| `en` | Английский | English |
| `ja` | Японский | 日本語 |
| `pt` | Португальский | Português |
| `nl` | Нидерландский | Nederlands |
| `es` | Испанский | Español |
| `zh` | Китайский (упрощённый) | 简体中文 |

Словари находятся в `src/i18n/<код>.json`. Сейчас в каждом 1715 одинаковых ключей.
Переключение обновляет интерфейс без пересоздания эмулятора. Выбор сохраняется
в настройках приложения (`msxlab.language`); язык по умолчанию — русский.

## Покрытие

Переведены меню, содержимое панелей, настройки, подписи кнопок и полей,
подсказки, диалоги и известные сообщения приложения. Перевод применяется при
отображении: значения настроек и ответы внешнего API остаются прежними.
Словари поставляются вместе с приложением и работают без сети.

CPU, VRAM, регистры и команды Z80, адреса, имена файлов, пользовательские метки,
комментарии и содержимое памяти не переводятся. Цитаты из справочных документов
и неизвестные сообщения сторонних компонентов сохраняют исходный язык.
Переводы подготовлены с машинной помощью и проверкой терминологии;
для окончательной языковой редакции полезна проверка носителями.

## Добавление перевода

1. Добавить один и тот же ключ во все семь JSON-словарей.
2. Обернуть только интерфейсный текст в `t('ключ')`.
3. Компонент вне обновляемого дерева должен подписаться через `useLanguage()`.
4. Не менять ID панелей, значения настроек, имена команд API и пользовательские данные.
5. Не использовать переведённые подписи как внутренние идентификаторы.

Если ключ отсутствует, используется английский текст, затем сам ключ. Для новых
параграфов предпочтительны смысловые ключи, например `settings.remote`.

Динамические сообщения описаны в `src/i18n/messages.json`, подписи областей памяти —
в `display.ts`, локализованные примеры команд — в `commands.ts`.
Нативные меню и диалоги используют `electron/i18n.cjs`.

Проверки: `npm run typecheck`, `node tests/languages.mjs`,
`node tests/i18n-coverage.mjs`, `node tests/i18n-render.mjs`.
После сборки и штатного обновления приложения появится выбор языка. Разработка
в боковой задаче не перезапускает открытое приложение пользователя.
