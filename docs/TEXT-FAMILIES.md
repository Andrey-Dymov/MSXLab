# Кодировки, форматы и профили текстов

Производитель — группа в каталоге, а не правило выбора декодера. Кодировка и формат хранения выбираются независимо; профиль игры связывает их с адресами драйвера. Автоопределение разрешено только по проверенному SHA-256 ROM.

## Проверено: King’s Valley

Konami. Кодировка: A=21h, цифра 0=10h, пробел=00h, ©=1Ah. Формат: адрес VRAM (LE), данные, FE для нового адреса, FF для конца. Профиль хранит базу ROM 4000h и процедуру вывода 4055h. На исходном ROM проверены GAME OVER, PUSH SPACE KEY, PLAY START, ©KONAMI 1985 и ©KONAMI.

В интерфейсе кодировка называется «Тайлы · A=21, 0=10, пробел=00», формат — «VRAM · адрес + данные · FE/FF». Старые идентификаторы kings-valley сохранены для совместимости существующих проектов и текстовых блоков. Это описательные названия механизмов, не заявление о едином стандарте Konami.

## Сравнение: Maze of Galious (Knightmare II)

Изучены локальные findtext.py и makemaps.py из коллекции Games source codes/Knightmare II (wijnen), а также MazeOfGalious.rom, SHA-256 420c42c18006eb5dbb25efa5b83e340d740824c15a714929a945c0db51f97280.

findtext.py: буква A имеет два кода 0Ah/0Bh; S — 2Eh/2Fh. Эти два кода представляют части буквы, а не строчные/заглавные буквы (регистр используется исследовательским скриптом для различения). Строка начинается с отступа и однобайтной длины. Код 00 — пробел. Скрипт начинает чтение с AE28h в группе страниц 0Fh, то есть ROM-смещение 1EE28h. Первые две записи имеют отступ 13, длину 5, данные 2F31272D3B и 2E30262C3A. Они не совместимы с кодировкой King’s Valley.

Декодер Maze of Galious ещё не добавлен: необходимо корректно объединить части букв и исследовать границы всех текстовых блоков. В список проверенных профилей игра не включена. Общая совместимость игр других производителей не заявляется.

## Расширение

Реестр src/backend/textProfiles.ts содержит отдельные списки кодировок, форматов и проверенных профилей, сгруппированных по производителю. Новая игра может повторно использовать существующие кодировку и формат, задавая собственные адреса. Профили без подтверждённого хеша не выбираются автоматически. Настройки и пользовательские таблицы хранятся в проекте и в сохранённых текстовых блоках.
